# ゲーミフィケーション機能 要件定義

## 概要

小学生向けマウス操作学習アプリに「熟達可視化型ゲーミフィケーション」を導入する。
競争ではなく、**昨日の自分より上手くなったか**を実感できる設計を目指す。

## 用語集

| 用語 | 定義 |
|------|------|
| 星評価 | ステージクリア時に★1〜★3で評価する仕組み |
| 実績バッジ | 操作別の熟達度に応じて獲得できるバッジ |
| 操作別統計 | クリック・ダブルクリック・右クリック・ドラッグの成功回数・成功率 |
| 連続成功 | ミスなく連続で正しい操作を行った回数 |
| メタ進行 | 1回のプレイを超えた長期的な進捗・成長の可視化 |
| 熟達レベル | 操作別の累計成功回数に基づくLv.1〜Lv.5のレベル表示 |
| きょうのれんしゅう | 日付ごとの練習目標と達成状況。毎日の練習習慣を促す仕組み |
| れんしゅうスタンプ | 日ごとにプレイした記録。連続日数を可視化する |

## スコープ

### Phase 1（本スコープ）
- ステージ星評価システム
- 実績バッジシステム
- 練習結果画面の強化
- 連続成功ボーナスの強化
- 操作別統計の集計
- ゲーミフィケーションデータの永続化

### Phase 2（本スコープ）
- 操作別熟達レベル

### Phase 2.5（本スコープ）
- 「きょうのれんしゅう」

### Phase 3（将来）
- 図鑑 / アルバム

### Phase 3（将来）
- 先生向け進捗確認
- クラス単位の達成表示

## ユーザーストーリーと受入基準

### US-1: ステージ星評価システム

**ストーリー**: 児童として、ステージクリア時に★1〜★3の評価を受けたい。上手にできたかどうかが分かるようにしたい。

**受入基準**:
- AC-1.1: ステージクリア時に、以下の3軸で★判定が行われること
  - ★1: ステージクリア（スコア・収穫数の目標達成）
  - ★2: 制限時間の20%以上を残してクリア
  - ★3: ミス率10%以下でクリア（ミス = 間違った操作でフルーツに触れた回数）
- AC-1.1a: ステージクリア条件達成時にゲームが即終了し、その時点の残り時間で星評価が算出されること
- AC-1.2: 各ステージの獲得済み星数がステージ選択画面に表示されること
- AC-1.3: 星評価がローカルストレージに永続化され、再訪問時に復元されること
- AC-1.4: より高い星評価を獲得した場合のみ上書きされること（低下しない）

### US-2: 実績バッジシステム

**ストーリー**: 児童として、特定の操作が上手になったことをバッジで確認したい。

**受入基準**:
- AC-2.1: 以下の4種類の操作別バッジが存在すること
  - クリック名人: クリック成功 累計30回
  - ダブルクリック達人: ダブルクリック成功 累計20回
  - 右クリックマスター: 右クリック成功 累計20回
  - ドラッグ博士: ドラッグ成功 累計15回
- AC-2.2: バッジ獲得時に祝福演出が表示されること
- AC-2.3: 獲得済みバッジが一覧画面で確認できること
- AC-2.4: バッジの進捗（現在の累計回数 / 目標回数）が確認できること
- AC-2.5: バッジデータがローカルストレージに永続化されること

### US-3: 練習結果画面の強化

**ストーリー**: 児童として、プレイ終了後に自分の成績を詳しく見たい。前回より上手くなったか知りたい。

**受入基準**:
- AC-3.1: ゲーム終了時に操作別の成功回数が表示されること
- AC-3.2: 前回のプレイ結果との比較（↑↓表示）が表示されること
- AC-3.3: 励ましメッセージが表示されること（成績に応じて内容が変わる）
- AC-3.4: 獲得した星評価が結果画面に表示されること

### US-4: 連続成功ボーナスの強化

**ストーリー**: 児童として、連続で正しい操作ができたときに特別な反応がほしい。

**受入基準**:
- AC-4.1: 3回連続成功時ににこにこ表示が出ること
- AC-4.2: 5回連続成功時にボーナスフルーツが出現すること
- AC-4.3: 10回連続成功時に「すごい！」演出が表示されること
- AC-4.4: ミス時に連続カウントがリセットされること
- AC-4.5: 連続成功数がUI上にリアルタイムで表示されること

### US-5: 操作別統計の集計

**ストーリー**: システムとして、各操作の成功・失敗を記録し、バッジ判定や結果画面に利用したい。

**受入基準**:
- AC-5.1: クリック・ダブルクリック・右クリック・ドラッグの成功回数をプレイ中にカウントすること
- AC-5.2: 各操作の失敗回数（間違った操作）もカウントすること
- AC-5.2a: 右クリック・ドラッグ操作の失敗（不正な対象への操作）も失敗としてカウントされること
- AC-5.3: 累計統計（全プレイ通算）がローカルストレージに保存されること
- AC-5.4: プレイごとの統計と累計統計が区別して管理されること

### US-6: ゲーミフィケーションデータの永続化

**ストーリー**: 児童として、ブラウザを閉じても自分の進捗が消えないようにしたい。

**受入基準**:
- AC-6.1: 星評価・バッジ・累計統計がローカルストレージに保存されること
- AC-6.2: ローカルストレージの読み込みエラー時にデフォルト値にフォールバックすること
- AC-6.3: データ破損時にアプリがクラッシュしないこと
- AC-6.4: 既存のステージ進捗・ハイスコアデータとの互換性が維持されること

### US-7: 操作別熟達レベル

**ストーリー**: 児童として、各マウス操作がどのくらい上手になったかをレベルで確認したい。練習を重ねるごとにレベルが上がるのを見たい。

**受入基準**:
- AC-7.1: 4種類の操作（クリック・ダブルクリック・右クリック・ドラッグ）ごとに熟達レベル（Lv.1〜Lv.5）が表示されること
- AC-7.2: 熟達レベルは累計成功回数に基づいて算出されること
  - Lv.1: 0回以上（初期）
  - Lv.2: 10回以上
  - Lv.3: 30回以上
  - Lv.4: 60回以上
  - Lv.5: 100回以上
- AC-7.3: レベルアップ時に祝福演出が表示されること
- AC-7.4: 操作別の熟達レベルがプロフィール画面（アイドル時）で一覧表示されること
- AC-7.5: 熟達レベルがローカルストレージに永続化されること（既存のcumulativeStatsから導出可能なため、追加保存は不要）
- AC-7.6: 各操作の現在の成功回数と次のレベルまでの残り回数が表示されること

### US-8: きょうのれんしゅう

**ストーリー**: 児童として、毎日少しずつ練習する習慣をつけたい。今日やるべきことと、やったことが一目でわかるようにしたい。

**受入基準**:
- AC-8.1: アプリ起動時に「きょうのれんしゅう」画面が表示され、今日の目標（各操作1回以上成功）が提示されること
- AC-8.2: 目標の達成状況がリアルタイムで更新されること（プレイ中に達成するとチェックが付く）
- AC-8.3: 全目標達成時に「きょうのれんしゅうクリア！」の祝福演出が表示されること
- AC-8.4: 今日プレイしたことが「れんしゅうスタンプ」として記録されること（1日1スタンプ）
- AC-8.5: 連続日数（れんしゅうストリーク）が表示されること
- AC-8.6: スタンプデータがローカルストレージに永続化されること
- AC-8.7: 日付が変わった場合、前日の目標がリセットされ新しい目標が提示されること
- AC-8.8: 時計を操作して不正にスタンプを取得しても、アプリがクラッシュしないこと

## 正確性プロパティ

| ID | プロパティ | 説明 |
|----|-----------|------|
| CP-1 | 星評価の単調性 | 一度獲得した星評価は、以降のプレイで低下しない |
| CP-2 | バッジの不可逆性 | 一度獲得したバッジは取り消されない |
| CP-3 | 統計の非負性 | すべての統計カウンタは0以上の整数である |
| CP-4 | 連続成功カウントの整合性 | 連続成功カウントは0以上で、ミス時に必ず0にリセットされる |
| CP-5 | 累計統計の単調増加 | 累計統計値は減少しない（各プレイの統計が加算される） |
| CP-6 | 永続化の冪等性 | 同じデータを複数回保存しても結果が変わらない |
| CP-7 | デシリアライズの安全性 | 不正なJSON入力に対してクラッシュせずデフォルト値を返す |
| CP-8 | 熟達レベルの単調性 | 累計成功回数が増加する限り、熟達レベルは低下しない |
| CP-9 | 熟達レベルの導出可能性 | 熟達レベルはcumulativeStatsから常に一意に導出でき、追加の永続化データに依存しない |
| CP-10 | スタンプの不可逆性 | 一度押されたスタンプは取り消されない |
| CP-11 | 連続日数の整合性 | 連続日数は実際のスタンプ日付列から正しく算出される |
| CP-12 | 日付境界の安全性 | 日付変更時にデータ破損やクラッシュが発生しない |
