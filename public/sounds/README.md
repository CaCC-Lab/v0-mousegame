# Sound Effects

This directory should contain the following sound effect files:

- `collect.mp3` - Sound played when a fruit is collected
- `game-start.mp3` - Sound played when the game starts
- `game-over.mp3` - Sound played when the game ends
- `high-score.mp3` - Sound played when achieving a new high score

## Recommended Sound Sources

You can obtain free sound effects from:
- [Freesound.org](https://freesound.org/)
- [Zapsplat.com](https://www.zapsplat.com/)
- [Mixkit.co](https://mixkit.co/free-sound-effects/)

## File Format

All sound files should be in MP3 format for best compatibility across browsers.
