# Sound Effects

This directory contains placeholder sound effect files. Replace them with actual sound files for the best gaming experience.

## Required Sound Files

- `collect.mp3` - Sound played when a fruit is collected or power-up is picked up
  - Recommended: Short, positive sound (0.2-0.5s) like a coin pickup or bell chime
  - Used for: All fruit collections and power-up collections

- `game-start.mp3` - Sound played when the game starts
  - Recommended: Upbeat, energetic sound (1-2s) that signals the beginning
  - Used for: Game start button click

- `game-over.mp3` - Sound played when the game ends
  - Recommended: Gentle, conclusive sound (1-2s) that signals completion
  - Used for: When timer reaches 0

- `high-score.mp3` - Sound played when achieving a new high score
  - Recommended: Celebratory, triumphant sound (2-3s) like fanfare or achievement unlock
  - Used for: New high score achievement

## Recommended Sound Sources

You can obtain free sound effects from:
- [Freesound.org](https://freesound.org/) - Community-driven, requires attribution
- [Zapsplat.com](https://www.zapsplat.com/) - Free with account, no attribution required
- [Mixkit.co](https://mixkit.co/free-sound-effects/) - Completely free, no attribution required
- [OpenGameArt.org](https://opengameart.org/) - Game-focused sounds
- [Soundbible.com](http://soundbible.com/) - Various licenses available

## File Format & Optimization

- **Format**: MP3 for best compatibility across browsers
- **Bitrate**: 128-192 kbps is sufficient for game sounds
- **Sample Rate**: 44.1 kHz recommended
- **File Size**: Keep under 100KB per file for fast loading

## Notes

The current files are empty placeholders. The game will work without sounds, but for the best experience, replace these with actual sound files. The SoundManager is configured to handle missing or failed audio gracefully.
