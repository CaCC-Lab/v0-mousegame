# PLiCy 公開手順書

日本のゲーム投稿サイト [PLiCy（プリシー）](https://plicy.net/) に HTML5 ゲームとして公開する手順。

itch.io 版と**同じ zip をそのまま使える**（理由は「配布ファイル」の節を参照）。

> 本書の PLiCy 側の仕様は公式 FAQ（[HTML5](https://plicy.net/ToolFAQ/HTML5)、[ヘルプ](https://plicy.net/ToolFAQ/Help)）の記載に基づく（2026-07 時点で確認できた範囲）。
> **未確認の項目には「要確認」と明記している**。画面の文言や仕様は変わることがあるため、実際の表示を優先すること。

---

## なぜ PLiCy にも出すのか

itch.io は英語圏のインディーゲーム利用者が中心で、日本語の学習ツールとは客層が合わない。
PLiCy は日本語のゲーム投稿サイトで、**小学生や保護者・先生が日本語で辿り着ける**。
このゲームの対象読者に届きやすいのはこちら。

## 配布ファイル

itch.io 用と同じものを使う。

```bash
npm run build:itch
```

→ `dist-itch/fruit-harvest-itch.zip`

### そのまま使える理由

ビルド時にすべての参照を相対パスへ書き換えているため、配信パスの形に依存しない。
実際に2つの形で動作を確認済み。

| 配信の形 | 例 | 結果 |
| --- | --- | --- |
| ルート直下 | `/index.html` | ✅ 起動・スプライト12枚すべて表示・404なし |
| サブパス | `/games/98765/index.html` | ✅ 同上 |

PLiCy がどちらの形で配信しても動く。

### PLiCy の要件との対応

| 要件 | 対応状況 |
| --- | --- |
| zip でアップロード | ✅ `fruit-harvest-itch.zip` |
| 起動ページが `index.html` | ✅ zip 直下にある（ビルド時に検査している） |
| 暗号化した zip は不可 | ✅ 暗号化していない |
| iframe の使用禁止 | ✅ 使っていない |
| ファイル名に絵文字を含まない | ✅ 英数字のみ |
| 日本語ファイル名 | ✅ 使っていない |

## アップロード手順

1. 右上の「ゲーム登録」から zip をアップロードする
2. 変換処理を待つ（**データ量により5分〜1時間**かかる）
3. ゲーム情報を入力する（次節）
4. 公開設定を確認して公開する

### 注意

- **1日にアップロードできる zip は10回まで**。試行錯誤は計画的に
- アップロード後の変換に時間がかかるため、締め切り直前の作業は避ける

## ゲーム情報の入力内容

| 項目 | 入力値 |
| --- | --- |
| タイトル | フルーツハーベスト |
| ジャンル | 学習・教育 / その他（**要確認**: PLiCy のジャンル一覧に合わせる） |
| 対象年齢 | 全年齢 |
| 操作方法 | マウス（クリック・ダブルクリック・右クリック・ドラッグ） |

### 紹介文（そのまま貼り付け）

```
マウスの練習ができるゲームです。

おちてくるフルーツを、それぞれちがうやりかたでとります。

🍎 りんご … クリック
🫐 ブルーベリー … ダブルクリック
🍋 レモン … 右クリック
🍉 スイカ … ドラッグ＆ドロップ

小学生がはじめてマウスをさわるときの練習用に作りました。
はんていはやさしめにしてあるので、うまくいかなくても大丈夫です。

■ とくちょう
・6つのステージ（1回1〜2分半）
・れんしゅうの記録が残る（操作ごとのレベルとバッジ）
・きょうのれんしゅう（4種類の操作を毎日ひとつずつ）
・むずかしさの切り替え（ふつう / むずかしい、うごくモードのオンオフ）
・日本語と英語の切り替え
・広告なし・アカウント登録なし（記録はブラウザの中だけに保存されます）

■ あそびかた
1. 「はじめる」をおす
2. おちてくるフルーツを、それぞれのやりかたでとる
3. じかんになったら けっかを見る

■ 対象
・はじめてマウスを使う小学生
・クリックやドラッグの練習をしたい方
・授業や家庭学習でマウス操作を教える先生・保護者の方

マウスを使うゲームなので、パソコンでのプレイをおすすめします。
（マウスのない端末では、その旨の案内が表示されます）

ソースコードは MIT ライセンスで公開しています。
https://github.com/CaCC-Lab/v0-mousegame
```

## 未確認の項目（公式で確認してほしいこと）

自動での情報取得が制限されていたため、以下は**実際の管理画面で確認が必要**。

1. **スクリーンショット撮影機能との相性**
   PLiCy には「ミニ実況」などゲーム画面を撮影する機能があり、FAQ に
   「スクリーンショットにcanvas以外の内容が撮影されません」との記載がある。
   **このゲームは canvas ではなく DOM で描画しているため、
   PLiCy 側の撮影機能では正しく写らない可能性がある。**
   ゲームのプレイ自体には影響しない見込みだが、実機で確認したい。

2. **サムネイルの推奨サイズ** — 630×500 のまま使えるか

3. **ジャンル区分** — 「学習・教育」に相当する分類があるか

4. **収益化の仕組み** — 広告収益の分配があるか、条件は何か

5. **外部リソースの可否** — 制限されても動くことは確認済み
   このゲームは Google Fonts（`fonts.googleapis.com`）から
   Fredoka / Nunito を読み込んでいる。
   FAQ に「外部サイトへの接続について」の項目があるため制限の可能性があるが、
   **外部接続を完全に遮断した状態で動作を確認済み**:

   | 項目 | 結果 |
   | --- | --- |
   | 起動 | ✅ |
   | フルーツのスプライト12枚 | ✅ すべて表示 |
   | 見た目 | 書体が標準フォントに変わるのみ（崩れなし） |

   日本語の文字はもともとフォールバック書体で表示されているため、
   影響はラテン文字（数字・英字）の書体に限られる。
   気になる場合は Fredoka / Nunito も同梱できる（絵文字フォントは同梱済み）。
